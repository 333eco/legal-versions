# Copyright and takedown

Draft of 26 November 2026.

This policy is for anyone who finds a file kept at storage.333.eco that uses their work without permission. storage.333.eco is where HeartBank® apps keep the photos, voices, videos and documents people choose to keep. It is run by the organization that will be named in the final version.

## How to report a file

Write to notice@333.eco. Please include:

- Who you are and how to reach you, and whether you own the work or act for the person who owns it.
- The work you say the file uses: what it is, and where the original can be seen if it is online.
- Where you saw the file: its B-Link, or the page where it appears. A file's storage address is never shown, so send the B-Link or the page.
- A statement that you believe in good faith that the work's owner or the law does not allow the file's use of it.
- A statement that the information in your notice is accurate.
- Your signature.

For any other report, such as a file that is unlawful or a private picture of you that you did not agree to, write to the same address with the B-Link or the page where you saw it.

## What storage.333.eco does

Nothing is removed automatically: a person decides. On a notice that names a file, we may end it. Ending a file on a notice:

- Deletes the file's bytes from the store.
- Removes its sealed second copy at Google Cloud Storage.
- Ends every file made from it, such as the small picture of a photo shown in a list, so none outlives it.
- Leaves a short row saying the file existed, and when it ended.
- Applies to a file that was given too. Otherwise a given file ends only when the person who holds it asks.

A removed file cannot be put back from storage.333.eco: its bytes and its copy are gone.

A B-Link that points to the file is kept at b.333.eco and may be ended there too. An ended link says that it was ended, and when.

## If your file was removed

If you believe a file you kept was removed by mistake, or because it was taken for something it is not, you can send a counter-notice to notice@333.eco. Please include:

- Who you are and how to reach you.
- Which file was removed: its B-Link, or the page where it appeared.
- A statement that you believe in good faith that the file was removed by mistake or because it was taken for something it is not.
- Your signature.

What we do with a counter-notice will be set out in the final version.
