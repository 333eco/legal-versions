# Privacy policy

Draft of 26 November 2026.

This policy covers storage.333.eco, where HeartBank® apps keep the photos, voices, videos and documents people choose to keep. It is run by the organization that will be named in the final version. You use it through an app (today, Keep a copy at origin.333.eco), and that app's own policy covers you too: the app decides who may see a file.

## What we keep about each file

- The file itself, as it was uploaded. Public files (such as the picture on a B-Link's card) and private files are kept in two separate places.
- Which app keeps it, and that app's own reference for the person who holds it. The app makes that reference; it is never a name, an email address or a phone number, and two apps' references to the same person cannot be matched here.
- What the file is: its kind, format, type, size and fingerprint (SHA-256); for a recording, its length, measured from the file; and whether a picture or video says where it was taken. A public picture that says where it was taken is refused.
- The days it was stored, given and ended.
- Each day, for each app and each holder, how many files and how many bytes were kept, so the app can charge for paid storage. The day counts for given files name no one.
- For a gift kept above its free size, the payment reference the app gave.

We keep no record of who opened a file, or when.

## The second copy

Every file is also copied to Google Cloud Storage in Singapore, sealed with a key Google never sees, so it survives the loss of the first store. Ending a file removes its copy too.

## How long

Until the file is ended. A file you keep ends when you ask your app. If the paid storage for a file you keep goes unpaid, your app may end it 90 days after it reports that, and until then you can save your own copy. A file someone gave you is yours: it ends only when you ask, never because of a payment. When a file ends, its bytes and its copy are deleted; a short row saying it existed, and when it ended, stays.

## Visits

This site's pages run no script and count nothing, and they set no cookies. This site runs on Cloudflare; we have turned off its request logs for this site. Cloudflare carries each request under its own policy.

## Who else sees a file

- The app that keeps it, and the people that app lets see it. A private file opens only through a short-lived permission the app asks for, an hour at most.
- A public file opens for anyone who has its address. That address is never shown or printed: a file is shared only through a B-Link.
- Cloudflare stores the files and runs this site, in Asia-Pacific.
- Google Cloud Storage holds the sealed second copy, which it cannot open.

We do not sell anything we keep, or use it for advertising.

## Reporting a file

Write to notice@333.eco with the B-Link or the page where you saw it.
